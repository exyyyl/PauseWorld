# WorldPause

Остановка мира для скриншотов в одиночной игре. Клавиша по умолчанию — **` / ~**;
её можно изменить в настройках управления Minecraft. Во время паузы игрок может
перемещаться, а значок часов показывает состояние мода. F1 скрывает значок.

## Версии и загрузчики

| Minecraft | Fabric | Forge | NeoForge | Java игры |
| --- | --- | --- | --- | --- |
| 1.20.1 | отдельный JAR, нужен Fabric API | общий JAR Forge | тот же JAR на NeoForge 47.1.106 | 17 |
| 1.21.1 | отдельный JAR, нужен Fabric API | отдельный JAR | отдельный JAR | 21 |

Каждый файл предназначен для **точной версии Minecraft**, указанной в названии.
Расширять диапазон в метаданных без проверки следующих версий не следует.
На 1.20.1 используется общий API Forge 47.1, сохранившийся в исходном форке
NeoForge. Для более новых NeoForge нужен отдельный файл.

Мод предназначен для клиента и встроенного одиночного сервера. Подключение к
внешнему серверу и мир, открытый по LAN, не поддерживаются. При открытии мира
по LAN пауза снимается. Совместная игра — задача будущего релиза.

## Сборка

Для запуска Gradle нужна **JDK 21**. Для сборки 1.20.1 также нужна JDK 17;
Gradle может загрузить её через настроенный resolver. В репозитории есть Gradle
Wrapper, отдельно устанавливать Gradle не требуется.

```sh
# Одна комбинация версии и загрузчика
./gradlew -Ptarget=1.21.1-neoforge build collectJars

# Все пять файлов (шесть комбинаций с учётом NeoForge 1.20.1)
./gradlew build collectJars

# Проверка метаданных, Java-версии и комплектности mixin/refmap в готовых файлах
python3 scripts/verify_artifact.py build/releases/*.jar

# Запуск клиента для проверки конкретной сборки
./gradlew -Ptarget=1.20.1-fabric :1.20.1-fabric:runClient
```

Допустимые значения `target`: `1.20.1-fabric`, `1.20.1-forge`,
`1.21.1-fabric`, `1.21.1-forge`, `1.21.1-neoforge`.
На Windows вместо `./gradlew` используйте `gradlew.bat`.
Например, в PowerShell: `.\gradlew.bat build collectJars`.
Устанавливаемые файлы собираются в `build/releases`. Исходники и промежуточные
dev JAR не нужно помещать в папку `mods`.

Результаты выполненных проверок и оставшиеся проверки на Windows:
[VALIDATION.md](VALIDATION.md).

## Структура

- `common/` — управление паузой, клавиша, звук, индикатор и переводы.
- `platforms/` — регистрация мода и клавиши, метаданные загрузчиков.
- `versions/<версия>/common/` — механизм заморозки и отличающиеся сигнатуры игры.
- `versions/<версия>/<загрузчик>/` — настройки конкретной сборки.

В 1.21.1 используется встроенный механизм заморозки тиков. На 1.20.1 отдельные
mixins останавливают симуляцию мира, сохраняя обработку игрока и загрузку чанков.
Изменение состояния встроенного сервера выполняется в его потоке. При снятии
паузы восстанавливается предыдущее состояние встроенной заморозки, если она
уже была включена другой командой.

## Проверка перед публикацией

CI собирает каждую цель отдельно и проверяет содержимое готового JAR.
Успешная компиляция не заменяет проверку поведения в игре. На каждой из шести
комбинаций, включая Forge и NeoForge 1.20.1 по отдельности, нужно проверить:

1. Запуск игры с выпускным JAR, создание мира и переназначение клавиши.
2. Остановку и возобновление мобов, снарядов, редстоуна, жидкостей и времени суток.
3. Передвижение игрока, загрузку новых чанков, голод, воздух и эффекты зелий.
4. Звуки мобов и игрока, инвентарь, меню Esc, индикатор часов и F1.
5. Выход из замороженного мира, повторный вход и открытие другого мира.
6. Открытие LAN во время паузы: мир должен возобновиться, клавиша — перестать
   включать паузу. Подключение к внешнему серверу не должно менять его состояние.
