# Проверка переноса

Дата: 17 октября 2026 года. Номер версии мода сохранён: **1.4**.

На macOS arm64 с JDK 21 и 17 выполнены:

- Отдельная сборка всех пяти целей: Fabric 1.20.1, Forge 1.20.1,
  Fabric 1.21.1, Forge 1.21.1 и NeoForge 1.21.1.
- Общая сборка `build collectJars` на загруженных зависимостях (`--offline`).
- Проверка метаданных, версий Java, ресурсов, классов mixin и production refmap
  в каждом из пяти готовых JAR.
- Запуск тестового клиента Fabric 1.21.1 и runtime-аудит Mixin без ошибок.

Это подтверждает сборку и загрузку проверенного клиента, но не заменяет
проверку поведения паузы на каждой комбинации.

## Следующий этап на Windows

1. Установить JDK 21 и JDK 17, получить изменения из репозитория.
2. Выполнить `.\gradlew.bat build collectJars`.
3. Проверить JAR: `py -3 scripts/verify_artifact.py "build/releases/*.jar"`.
4. Пройти игровой список проверок в [README.md](README.md) на всех комбинациях.
5. Отдельно проверить JAR Forge 1.20.1 на **NeoForge 47.1.106**.
   Общий файл использует совместимый API Forge 47.1; запуск на этом NeoForge
   пока не проверен.

Мультиплеер и LAN в текущую работу не входят.
